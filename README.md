# Prime Stone Showcase

Create a modern, premium, responsive website for a natural stone company called **Prime Impex Stones**.

The company specializes in **Indian marble, granite and quartzite**, with a focus on premium natural stone and global exports.

## Overall Website Requirements

Build a professional **4-page website** with these pages:

1. Home
2. Products
3. About Us
4. Contact Us

The website should look like a **premium marble and natural stone export company**, not like a generic template.

### Design Style

Use a luxurious, elegant and minimal visual style inspired by premium marble showrooms and architecture.

Design direction:

* Premium
* Elegant
* Modern
* Clean
* Luxury
* Natural stone / architectural aesthetic
* Professional B2B export company feel

Use a sophisticated color palette based around:

* Warm white / ivory
* Marble beige
* Stone grey
* Charcoal / black
* Subtle gold or bronze accents

Avoid excessive colors.

Use high-quality marble and architectural imagery throughout the website.

Typography should feel premium and sophisticated. Use a combination of:

* Elegant serif font for major headings
* Clean modern sans-serif font for body text and navigation

The website must be fully responsive for:

* Desktop
* Tablet
* Mobile

Add subtle animations and smooth transitions, but keep them professional and not excessive.
